# Data

Raw datasets are not committed (see `.gitignore`).

## Olist (Project 1)
Download from Kaggle: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce (license CC BY-NC-SA 4.0 — keep attribution).
Load into BigQuery as tables named `olist_orders_dataset`, `olist_order_items_dataset`, `olist_order_payments_dataset`, `olist_customers_dataset`, `olist_products_dataset`.

## Synthetic recruiting data (Project 2)
Generate with a script you add here (e.g. `generate_recruiting_data.py`) following `docs/recruiting-data-model.md`. Commit the script, not personal data.

## GA4 sample (Project 3)
Queried directly in BigQuery: `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`. Nothing to download.

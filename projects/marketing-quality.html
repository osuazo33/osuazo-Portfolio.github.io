PROJECT 03 · ANALYTICS ENGINEERING

Marketing Attribution & Quality Monitor

Analyze ecommerce events and design repeatable checks for data completeness, freshness, and consistency.

Data source

Google Analytics 4 public ecommerce sample: bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*. Start with a small date range and inspect the schema before developing funnel logic.

Metrics

  • Users and sessions by source, medium, and campaign when those fields are available and correctly extracted
  • Product view → add-to-cart → purchase funnel, with event definitions documented
  • Purchase event counts and purchase value, validated against the chosen schema
  • Cost per acquisition and ROAS only if reliable campaign spend and attributable conversions are available

Data quality

Record the test name, run timestamp, affected row count, severity, and resolution for each validation. Examples: missing user identifiers, unexpected event volume, duplicated transaction IDs, and stale data.

SQL and dashboard

Start with the SQL starter template. Add the published dashboard URL and findings only after validation.

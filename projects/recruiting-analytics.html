PROJECT 02 · BUSINESS OPERATIONS

Recruiting & Vacancy Performance

A synthetic recruiting data model to analyze open roles, candidate conversion, time-to-fill, and aging vacancies.

Data model

Use synthetic records only. Suggested tables: jobs, candidates, applications, recruiters. Give each entity a stable ID and define the grain of each table before joining.

See the proposed data model.

KPIs

  • Open vacancies as of the reporting date
  • Time-to-fill, with a documented start and end date
  • Application-to-interview and interview-to-hire conversion
  • Vacancy aging buckets and stale-update alerts
  • Candidate source effectiveness, with sample-size caveats

Automation plan

Build an n8n workflow that checks open roles daily, identifies roles above a configurable aging threshold, logs each run, and sends a test alert. Mark it as implemented only after it runs successfully.
